# your-space-ai

This unscoped package only holds the name `your-space-ai` for [Your Space](https://docs.getyourspace.ai); it isn't the `@your-space-ai` organization. It has no dependencies, and its `your-space-ai` command runs nothing: it prints where to find Your Space on npm and exits. Your Space's packages, including its command-line tool `@your-space-ai/cli`, are published by the [your-space-ai organization](https://www.npmjs.com/org/your-space-ai). Run the CLI with a pinned version, `npx @your-space-ai/cli@<version>`, as the [installation guide](https://docs.getyourspace.ai/install) shows.
