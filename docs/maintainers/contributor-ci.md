# Checking an outside contribution

The required **Contribution checks** job includes sign-off verification, dependency review, and the code checks selected by the PR diff. GitHub's MIT-licensed [Dependency Review Action v5.0.1](https://github.com/actions/dependency-review-action/tree/bbc44d14a204704ccc493733616cd1e93a0321ec) reads the dependency graph diff and fails on newly introduced moderate or higher advisories, including development tools. It runs on a hosted runner with read-only access. The action ships only in CI. Existing vulnerabilities have separate Dependabot, CodeQL and container scans.

Before approving an external run, inspect the changed workflow and every script it invokes. GitHub Actions requires approval for all external contributors. Keep fork tokens read-only, secrets unavailable, and PR jobs on GitHub-hosted runners. The public repository's CircleCI project has fork builds and sharing secrets with forks disabled. CircleCI status is therefore optional for external PRs. Full browser coverage runs on main. Keep the protected Mac signing runner restricted to the release workflow and protected main environment. Check these provider settings again when adding a trigger or runner group.
