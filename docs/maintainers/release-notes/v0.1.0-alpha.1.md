Your Space is a personal dashboard you run with Docker on your own Mac or Linux machine. Install
self-hosted apps from their kits, use them side by side, and give AI agents their own keys to read
from the apps you choose.

**This is an alpha, for trying Your Space out.** Read the
[alpha limits](https://docs.getyourspace.ai/install#alpha-limits) before you rely on it.

## Install

On a Mac or Linux machine with a running Docker engine and Node 22.12 or newer:

```sh
npx @your-space-ai/cli@0.1.0-alpha.1 setup
```

npx doesn't install the command: put `npx @your-space-ai/cli@0.1.0-alpha.1` in place of `your-space`
in every later command, or install it with `npm install -g @your-space-ai/cli@0.1.0-alpha.1`.

| Download | For |
| --- | --- |
| `your-space-macos-arm64-0.1.0-alpha.1.dmg` | The Mac app, Apple Silicon |
| `your-space-macos-x64-0.1.0-alpha.1.dmg` | The Mac app, Intel |
| `your-space-macos-arm64-0.1.0-alpha.1.zip`, `your-space-macos-x64-0.1.0-alpha.1.zip`, `latest-mac.yml` | The Mac app's updates, which the app downloads itself |
| `your-space-linux-x64`, `your-space-linux-arm64` | The `your-space` command on Linux without Node |
| `your-space-linux-licenses.txt` | The licenses of the code inside the Linux executables |
| `your-space.tar.gz` | The Compose files, for installing [by hand](https://docs.getyourspace.ai/install/manual) |
| `SHA256SUMS` | Checking any download |

The [installation guide](https://docs.getyourspace.ai/install) covers each path, and the
[Mac guide](https://docs.getyourspace.ai/install/macos-desktop) covers the app.

## Update later

To move an installation to a later release, run `npx @your-space-ai/cli@latest upgrade` in its
folder, or `npm install -g @your-space-ai/cli@latest` and then `your-space upgrade`. `upgrade` backs
up the database first, and puts the previous version back if the new one doesn't start. The Mac app
updates itself.

## Requirements

- Linux with Docker Engine 28.3.3 or newer, or macOS with a Docker-compatible engine such as
  OrbStack, Colima or Docker Desktop.
- Docker Compose 2.26.0 or newer.
- Node 22.12 or newer for the npm package. The standalone executables and the Mac app bring their own.
- macOS 13.5 or newer for the Mac app.

## Known limits

- No backup or restore, apart from the database backup `upgrade` makes before it changes anything.
  Your account, workspace and app data are in Docker volumes; don't delete them.
- No uninstall command. To remove Your Space, remove each app with its data in Apps first, then
  follow [Remove Your Space](https://docs.getyourspace.ai/operate#remove-your-space).
- Apps install only from their kits: from a link to a kit in a public GitHub repository, or, for a
  kit in a private repository, with `install-app --kit -` on the machine that runs Your Space. There
  is no GitHub connection, no managed repositories, no kit directory and no custom Home.
- `install-app` passes no values, so a kit with an `ask: true` value installs only from the review in
  Apps, and a kit in a private repository that needs one can't be installed yet.
- A newer kit reaches an installed app only when you remove the app, keeping its data, and install it
  again.
- Agents only read: a kit can't give them routes that create or change records.
- One account: only the owner signs in.
- No email. A new set-password link comes from `your-space owner reset-link`.

## Report a problem

[Open a bug report](https://github.com/your-space-ai/your-space/issues/new?template=bug_report.yml)
with your version, install path, platform and Docker versions. Issues are public: leave out
set-password links, keys and private data. Report a security problem privately, as the
[security policy](https://github.com/your-space-ai/your-space/blob/main/SECURITY.md) describes.
