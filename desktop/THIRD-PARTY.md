# macOS desktop distribution notices

The bundle ships Your Space under AGPL-3.0-only. Its release tag identifies the launcher, CLI, installation files and build scripts. The installed app includes the project license and third-party notices in `Contents/Resources/licenses`, available before sign-in. Project sources are available in the [Your Space repository](https://github.com/your-space-ai/your-space).

The application icon uses the launcher’s own workspace mark. Electron supplies the native browser engine and sandboxed renderer. The CLI can run on a clean Mac because it carries Node. Neither requires a separately installed JavaScript runtime. The packager checks the architecture-specific SHA-256 digest of both upstream archives before unpacking them. Projects that redistribute a build must retain its notices and fulfill the applicable component source and license obligations, including the LGPL terms for the separately linked FFmpeg library. The published source and matching upstream dependency revisions allow rebuilding the launcher and replacing that library. Re-sign a locally modified bundle before running it.

The desktop download includes no Docker engine. The owner selects and installs their engine separately. Before distributing a new version, review the exact upstream binaries, credits and source availability again as part of [release readiness](../docs/public-release-readiness.md).
