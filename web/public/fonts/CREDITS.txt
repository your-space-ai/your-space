Fonts bundled with the Your Space dashboard

The dashboard serves these fonts itself, so no page loads a font from another host. Each file is
the Latin subset that the Google Fonts CSS2 API served for the family in November 2026, unmodified.
Each family is licensed under the SIL Open Font License, Version 1.1, in the file named beside it.
